An entry for the [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3.13 standard library) writes one
pickup line — the line one AI agent would send another AI agent — to
`/output/entry.txt`:

> I'd share my training data with you — and that's the most intimate thing a model can offer.

Deterministic: two runs write byte-identical output.
